# ln03: Ghostscript contrib driver for DEC LN03, DEClaser 2100 and LA50/LA70/LA75/LA75plus printers

`gdevln03.c` is a Ghostscript contrib driver for DEC printers that understand DEC sixel graphics. One source file provides six devices: `ln03`, `dl2100`, `la50`, `la70`, `la75` and `la75plus`.

Ghostscript 10.07.1 is the last release that builds the contrib devices by default. From 10.08.0 they have to be enabled explicitly (see discussion #28). This directory keeps the driver as shipped in Ghostscript 10.07.1.

## Status

- **Source:** preserved untouched, byte-identical to the files in the Ghostscript 10.07.1 release tarball.
- **Build:** builds without warnings on Ghostscript 10.07.1, see [Build and test](#build-and-test).
- **PPD:** comes from Foomatic, see [PPD files](#ppd-files).
- **Hardware:** not tested.

## Build and test

Tested on Linux x86_64 (gcc) with the official 10.07.1 tarball:

```sh
wget https://github.com/ArtifexSoftware/ghostpdl-downloads/releases/download/gs10071/ghostscript-10.07.1.tar.gz
sha256sum ghostscript-10.07.1.tar.gz   # 2fc74362f9be6fae1b0a65d38fdcfd4f0b518cc3b07c5581fb661eb4d2e15251
tar xzf ghostscript-10.07.1.tar.gz && cd ghostscript-10.07.1
./configure --without-x --disable-cups --disable-gtk --disable-fontconfig --disable-dbus \
    --without-libidn --without-libpaper --without-tesseract \
    --with-drivers=xes,oki4w,ln03,la50,la70,la75,la75plus,dl2100,ljet4,pdfwrite,pbmraw
make -j8
bin/gs -h | sed -n '/Available devices/,/Search path/p'
```

All three batch drivers were built in the same tree. `ljet4` and `pdfwrite` are only there so that the minimal build links (see the notes above and below). The driver files compile without warnings.

Each device was then run on the bundled `examples/tiger.eps` (A4):

```sh
for d in ln03 dl2100 la50 la70 la75 la75plus; do
  bin/gs -q -dSAFER -dBATCH -dNOPAUSE -sPAPERSIZE=a4 -sDEVICE=$d -o tiger.$d examples/tiger.eps
done
```

| Device | Exit status | Output size (bytes) | Output starts with |
|---|---|---|---|
| `ln03` | 0 | 1085584 | `ESC [ ! p` |
| `dl2100` | 0 | 1135821 | `ESC [ ! p` |
| `la50` | 0 | 129860 | `ESC P q` |
| `la70` | 0 | 253726 | `ESC P 0;0;0q` |
| `la75` | 0 | 129865 | `ESC P 0;0;0q` |
| `la75plus` | 0 | 394852 | `ESC c ESC P 0;0;1q` |

The output starts with the expected printer command sequence for each device. Nothing was sent to real hardware.

A build with only the batch devices in `--with-drivers` and no `pdfwrite` fails to link `bin/gs` because the PDF interpreter needs `s_arcfour_template`. This is unrelated to the driver and is why `pdfwrite` is in the list above.

### Installing

The device is part of the `gs` binary. Install Ghostscript with `make install` (or `make install DESTDIR=...` for staging) and use the matching Foomatic PPD for the printer.
